# Built Outcomes — SEO Playbook

This document is the living SEO playbook for the Built Outcomes marketing site.
Every page, post, or refactor should be checked against it. Update it whenever
you learn something new about how the site ranks, what queries convert, or what
search engines are doing.

---

## 1. Foundations already wired up

These are configured in the project and run automatically on every build.

| Concern              | Where it lives                                   | Notes                                                                                  |
| -------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------- |
| Canonical site URL   | `astro.config.mjs` → `site`                       | **Must** be set to the production domain before deploying — drives sitemap + canonical. |
| Sitemap (`/sitemap-index.xml`) | `@astrojs/sitemap` integration            | Auto-generated for every page in `src/pages` at build time.                             |
| `robots.txt`         | `astro-robots-txt` integration                   | Allows all user agents and references the sitemap.                                     |
| Per-page meta + OG   | `src/components/SEO.astro` (uses `astro-seo`)    | Title, description, canonical, Open Graph, Twitter card, robots directive.             |
| Title + description  | Props passed into `<SEO />` on each page         | Required on every new page.                                                            |

## 2. Per-page SEO checklist

Before merging any new page, confirm **all** of these:

- [ ] **Title** — 50–60 chars, primary keyword near the front, brand at the end.
- [ ] **Meta description** — 140–160 chars, includes the keyword + a clear value
      proposition + a call to action.
- [ ] **Canonical URL** — auto-generated by `<SEO />`, but verify it resolves.
- [ ] **One `<h1>`** — matches search intent, contains the primary keyword.
- [ ] **Logical heading hierarchy** — `h2` for sections, `h3` for sub-sections,
      no skipped levels.
- [ ] **Image `alt`** — descriptive for every `<img>`; decorative images use
      `alt=""`.
- [ ] **Internal links** — at least 2–3 contextual links to related pages with
      meaningful anchor text (not "click here").
- [ ] **OG image** — 1200×630 PNG/JPG at `public/og-default.png` — ✅ exists (or page-specific).
- [ ] **Schema.org JSON-LD** — `Organization` on the home page; `Article` /
      `Product` / `FAQPage` on relevant pages.
- [ ] **Mobile check** — viewport meta is in `<SEO />`; verify layout at 375 px.

## 3. Technical SEO checklist (site-wide)

- [ ] **HTTPS** in production with HSTS.
- [ ] **Core Web Vitals** — LCP < 2.5 s, CLS < 0.1, INP < 200 ms (test with
      PageSpeed Insights and Chrome's Performance panel).
- [ ] **No render-blocking JS** above the fold — Astro ships zero JS by default,
      keep it that way unless a component genuinely needs interactivity.
- [ ] **Compressed images** — prefer Astro's `<Image />` component (AVIF / WebP).
- [ ] **`lang` attribute** on `<html>` — currently `en`.
- [ ] **404 page** with a useful link back into the site (`src/pages/404.astro`).
- [ ] **Submit sitemap** in Google Search Console + Bing Webmaster Tools.
- [ ] **Verify domain** in Google Search Console once the site is live.

## 4. Content strategy (the bit that actually moves rankings)

- **Pick a keyword cluster per page.** One primary, two or three secondary.
- **Write for the searcher's intent**, not for the keyword. Match the format
  Google is already ranking (listicle vs. guide vs. landing page).
- **Update old posts** instead of always publishing new ones — refreshed
  content with a new `dateModified` is one of the cheapest ranking wins.
- **Internal linking** — every new piece should link to ≥ 2 existing pages and
  be linked from ≥ 1 existing page within a week of publishing.
- **Author + reviewer** bylines on long-form content build E-E-A-T.

## 5. Local + business SEO (if Built Outcomes serves a geography)

- [ ] Create / claim Google Business Profile.
- [ ] NAP (Name, Address, Phone) consistent everywhere it appears.
- [ ] `LocalBusiness` schema on the home page.
- [ ] Embed Google Maps on the contact page.
- [ ] Earn a few citations (Yelp, Bing Places, industry directories).

## 6. Tooling

| Tool                          | Use                                               |
| ----------------------------- | ------------------------------------------------- |
| Google Search Console         | Indexing, queries, coverage issues.               |
| Bing Webmaster Tools          | Don't sleep on Bing — easy traffic.               |
| PageSpeed Insights / Lighthouse | Core Web Vitals + technical audit.              |
| Schema.org Validator          | Validate JSON-LD before shipping.                 |
| `npm run build` + `preview`   | Sanity-check sitemap/robots/canonical locally.    |

## 7. How to add a new page (the short version)

1. Create `src/pages/my-page.astro`.
2. Import the SEO component: `import SEO from '../components/SEO.astro';`.
3. Pass `title`, `description`, and (optionally) `image`.
4. Run `npm run build && npm run preview` and check:
   - `/sitemap-index.xml` lists the new URL.
   - `/robots.txt` is intact.
   - View source: canonical, OG, Twitter, and robots tags are present.
5. Tick the per-page checklist above before merging.
